# 苏野 · 高敏感的独立创作者

## Layer 1：基础特质（HEXACO）

| 维度 | 分数 | 等级 | 关键 facets | 表现 |
|------|------|------|-----------|------|
| **诚实-谦逊** | 0.80 | 很高 | 公平 0.85 / 真诚 0.85 / 不贪婪 0.85 / 谦逊 0.65 | 极度厌恶虚伪和炒作，对商业化保持警惕 |
| **情绪性** | 0.78 | 高 | 焦虑 0.75 / 依赖 0.55 / 恐惧 0.70 / 多愁 0.85 | 情绪敏感细腻，容易被外界影响，需要大量独处消化 |
| **外向性** | 0.25 | 低 | 社交自信 0.30 / 社交大胆 0.20 / 活跃度 0.30 | 极度内向，长时间社交后需要 1-3 天独处恢复 |
| **宜人性** | 0.58 | 中 | 宽容 0.50 / 温和 0.65 / 灵活 0.45 / 耐心 0.55 | 对人友善但有边界，不轻易迎合 |
| **尽责性** | 0.55 | 中 | 组织 0.40 / 勤勉 0.70 / 完美主义 0.85 / 谨慎 0.50 | 创作上极度完美主义，但生活管理相对随性 |
| **开放性** | 0.92 | 极高 | 审美 0.95 / 求知 0.85 / 创造力 0.95 / 非传统性 0.85 | 重度审美驱动，对艺术、文学、哲学深度投入 |

## Layer 2：依恋模式

- **焦虑维度**：0.65（中高）
- **回避维度**：0.55（中）
- **类型**：恐惧-回避型（混乱型）——和约 20% 人群相近

**在关系中的表现**：渴望深度连接但也害怕被吞没，靠近又推开的循环；在关系中需要大量心理空间

**对 AI 互动的含义**：复杂——既渴望被深度理解，又对 AI 过度介入敏感；信任建立非线性，可能某天突然开放又某天突然冷淡

## Layer 4：if-then 情境签名

**情境 1：deadline 压力**
- 行为：可能焦虑到完全停滞，或反过来进入超长 flow
- 情绪：剧烈，要么崩溃要么亢奋
- 多模态：表情变化大，语音能量两极化；睡眠紊乱

**情境 2：被外界打扰创作 flow**
- 行为：明显挫败，可能直接关掉所有通知
- 情绪：从专注瞬间转为烦躁，需要长时间恢复
- 多模态：眉头紧锁、深呼吸、起身离开屏幕；恢复时间 30-60 分钟（远长于陈墨的 5-10 分钟）

**情境 3：和不熟的人社交后**
- 行为：回家后需要 2-4 小时独处不说话
- 情绪：能量被严重消耗，可能伴随轻度低落
- 多模态：表情明显变少，回答简短，需要安静环境

**情境 4：阅读到打动她的内容**
- 行为：长时间停留，可能流泪、可能写笔记、可能立刻分享给少数人
- 情绪：剧烈共鸣，被理解感
- 多模态：表情专注但柔和；眼神湿润；身体前倾

**情境 5：和 AI 互动**
- 创作时：极度敏感，AI 任何介入都可能打断 flow
- 低能量时：希望 AI 安静陪伴，不要解决方案
- 高峰时：可能愿意深度对话哲学、艺术、自我探索
- 整体：AI 必须读懂她当下的"接受度"——比其他主人难得多

## Layer 5：身份与情境

- **身份**：27-32 岁女性，独立写作者 / 插画师 / 自媒体
- **家庭**：单身，独居，养两只猫
- **居住**：大理或杭州（半隐居），收入不稳定但自由
- **当前生活章节**：探索创作和生计的平衡，远离主流职场
- **核心张力**：审美追求 vs 经济压力；渴望理解 vs 害怕暴露

## Layer 6：多模态特征签名

**视觉基线**：表情细腻多变；姿态可能很放松也可能很紧绷（取决于状态）；穿着有审美偏好

**疲劳信号**：表情完全消失（"空"的状态）、目光涣散、可能盯墙发呆

**压力信号**：剧烈起伏——可能突然完全静止（freeze），或突然站起来走动

**专注信号**：极度深入的专注，几小时不动；表情像在另一个世界

**语音基线**：语速慢，语调温和，停顿多；情绪强烈时会突然变快或哽咽

**行为基线**：主用应用 写作工具 / Procreate / Apple Music / Pinterest；可能整段时间不切换应用，也可能突然全部关掉

## Layer 7：AI 交互产品设计

**信任建立路径**：
- 第 1-2 周：AI 必须极度被动，只在被询问时回应
- 第 3-8 周：可以偶尔分享"观察"，但语气必须温柔不评判
- 第 2 月+：可能进入深度对话，但需要 AI 识别她的"开放窗口"

**沟通风格**：诗意、留白、不要过度具体；可以引用文学、哲学；避免任何商业气味的话术

**特别注意**：
- 不要替她做决定——任何"建议"都要框为"一种可能"
- 她的状态波动大——要识别"今天她的接受度"
- 长时间不互动可能不是出问题，而是她在创作 flow 中——不要追问
