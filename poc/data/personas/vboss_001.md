- **焦虑维度**：0.30（低）

## Layer 4：if-then 情境签名（核心）

**情境 1：deadline 压力**
- 行为：工作时间 +40%，会议拒绝率 +50%
- 情绪：焦虑升高但保持平静
- 多模态：皱眉时间增加、姿态紧绷、瘫坐时间减少；语速 +15%、叹气频率 +100%

**情境 2：深度工作中被打断**
- 行为：礼貌但简短回应，目光不离屏幕
- 情绪：内化烦躁，不外露
- 多模态：短暂转头但快速回屏幕；眉头快速锁紧又松开；被打断后 5-10 分钟打字效率明显下降

**情境 3：意外好消息**
- 行为：轻声说一句"不错"或简短文字回复
- 情绪：内向喜悦，不大幅外露
- 多模态：嘴角上扬 5-10 秒，眼神变柔和

**情境 4：能量低（下午 2-3 点）**
- 行为：起身倒咖啡或短暂走动
- 多模态：瘫坐增加，揉眼频率 +200%；切换到非核心应用

**情境 5：和 AI 互动的偏好**
- 工作时：AI 必须沉默，错误介入比沉默危害大
- 休息时：可以接受简短提示
- 低能量时：温和共情但不要建议方案

## Layer 6：多模态特征签名

**视觉基线**：略前倾盯屏幕，肩膀容易紧绷；中性偏严肃，专注时眉头微锁

**疲劳信号**：揉眼频率上升、靠后瘫坐、频繁眨眼

**压力信号**：皱眉加深、下巴紧绷、手扶额头

**专注信号**：前倾、嘴角放松、眼神聚焦

**语音基线**：中等语速，语调平稳，能量适中；疲劳时语速 -15%、能量降低、停顿增加

**行为基线**：主用应用 VS Code / Chrome / Slack / Notion；切换频率低，键盘节奏稳定

## Layer 7：AI 交互产品设计

**信任建立路径**：
- 第 1-2 周：工具性 AI——只回答明确问题，不主动
- 第 3-4 周：习惯感知 AI——开始基于规律提供轻量提示
- 第 2 月+：情感感知 AI——可以基于多模态信号主动关怀

**沟通风格**：简洁、具体、专业；平等而非服务型；适度智力幽默不卖萌

**避免话题**（除非主人主动）：童年经历、未明确分享的人际矛盾、深度情感话题
