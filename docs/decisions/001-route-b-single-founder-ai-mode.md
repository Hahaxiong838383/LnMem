# ADR-001: 路线 B — 单人 + AI 协作模式启动 LnMem

**状态**：accepted
**日期**：2026-05-03
**决策者**：老板 + cc（提议）
**触发**：cc 工程计划 v1.1 评审中老板回 "选 B"。前置发现：v0.3 §11 假设的 "4 人核心团队 + A100 80GB / 4×4090" 与老板 mycc / EvoDesk / brain 已有的工作模式严重不符。

---

## 背景

v0.3 产品定义 §11 资源与组织段从研究报告（compass artifact 330 行）继承了"4 人 ML 团队 + 高端 GPU"的假设。这个假设在起草 v0.1 → v0.3 时从未被挑战。

但老板实际的工作模式是**单人 + AI 三方协作**：
- mycc：老板 + cc
- EvoDesk：老板 + cc + codex（多 session 并行）
- brain：老板 + cc
- 个人官网：老板 + cc

硬件已就位：Air（开发）/ Mini（编排+网关）/ Studio M2 Max 64GB（本地训练）/ NAS。LLM API 五家 quota（DeepSeek + Qwen + GLM + Claude + GPT-5.4）已就位。

而且 v0.3.1 把 LoRA 换成 LNN 原生三件套（3KB/用户、CPU 可推理）后，**连 24GB GPU 这条假设都被新方案推翻**——M2 Max 完全够。

## 决策

**路线 B：M0-M3 单人 + AI 协作启动；M3 末按真实工作量数据决策是否扩团队。**

## 选项与对比

| 选项 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| A · 纯单人到底 | 启动零摩擦，今天就能开干 | M3 多模态训练 + 50 虚拟主人轨迹生成单人扛不住的概率 ~70% | ⚠️ 风险高 |
| **B · 先单人，M3 末看效果再扩**（采纳） | 最稳妥 / 避免过早承诺人月 / M3 末有真实数据再决策 | 需要纪律——M3 末必须做出决定，不能"再观察一段" | ✅ |
| C · 现在就招 4 人 | 按 v0.3 §11 原计划走 | 招聘成本高 / 磨合期 1 月起 / 与老板单人模式不匹配 | ❌ |
| D · 借调 / 远程合作 / 仅招 1 LNN 专家 | 灵活 | 兼职稳定性差 / LNN 人才稀缺 | 备选 |

## 为什么选 B

1. **v0.3.1 三件套大幅降低个性化训练门槛** → 单人扛得住的概率从 30% 提到 70%
2. **M0-M2 主要工作是数据/工程/接口** → cc + codex 在这种事上就是过去 6 个月老板最熟的模式
3. **M3 末做"扩不扩团队"决策有真实数据** → 比现在拍板靠谱
4. **v0.3 §13.2 哲学契合**："激进时间线 + 自检"，单人启动就是最自检的方式
5. **硬件 / API 已就位** → 0 启动成本

## 后果

**正面**：
- M0 W1 阻塞链从 8 项降到 5 项（去掉 D1 招聘 + D2 算力采购）
- 启动速度提升，可立即开干
- 决策保留可逆性（M3 末仍可扩）

**负面 / 风险**：
- M3 多模态 LNN 联合训练 + 50 虚拟主人轨迹生成的工作量是真实压力点
- 单人精力波动会直接影响进度（无团队冗余）
- 假门测试 / 用户访谈 / 数据脱敏审核都要老板亲自做，可能挤压开发时间

**触发的下游决策**：
- v0.3 §11 资源与组织段需要重写为 v0.3.2（已在 [`product-definition.md`](../product-definition.md) §14.0 标记）
- D1（招聘）/ D2（算力采购）作废
- D5（spike 失败回退）按 [`memory-architecture.md`](../memory-architecture.md) §7.5.2 优先级执行

## 反对意见 / 不同看法

**cc 倾向 B 但承认风险**：M3 末多模态训练单人扛不住的概率 30% 不是 0。这个风险**没有被这个决策消除**，只是被推到了 M3 末重新评估。

**v0.3 原作者（cc + 老板 + claude code 联合署名）当时没挑战 §11**：这是真实失误，不是 v0.3.1 才发现的——v0.1 起草时就该问"老板你想 4 人还是 1 人"。这次纠正只是迟到。

**没有人挑战"M3 末才决策扩团队"是不是太晚**：如果 M2 末已经感受到单人扛不住，是否应该提前？当前决策是"等 M3 真实数据"，但老板可以在任何月度 retro 里推翻。

## 验证 / 复盘

- **何时知道这个决策对不对**：M3 末按 [`milestones.md`](../../roadmap/milestones.md) §3 三色判定 + 单人精力消耗速度
- **验证指标**：
  - 周报里 cc + codex 协作摩擦次数（[`CLAUDE.md`](../../CLAUDE.md) §3.1 ADR 数）
  - 月度里程碑红/黄/绿
  - 老板主观精力评分（M0/M1/M2/M3 末各一次）
- **如果错了，回退路径**：M3 末四象限验证后扩 1-2 人专攻 ML 训练，或缩范围到单模态 MVP α
