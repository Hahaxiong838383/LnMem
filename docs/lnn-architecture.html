1. 一句话理解 LnMem 与 LNN

LnMem = Liquid neural Memory，要做「能陪你数年、越用越懂你」的 AI 伙伴。

它和市面 AI 不一样的地方就一句：不是用文本存历史让大模型现读，而是让 LNN 像神经元一样持续演化，把"你是谁"沉淀到几 KB 的物理参数里。

📌 类比：ChatGPT vs LnMem

  • ChatGPT：每次对话翻笔记本回顾你说过的话（RAG/向量检索）。
    关掉聊天 → 它"忘"了你，下次重新翻。
  • LnMem：内部有个微型神经"心脏"，每秒接收你的表情/姿态/语音，它的每个神经元的时间常数（τ）都在持续被你影响。
    3 天后这个心脏的参数已经长得"像你专属"，不需要翻历史就能预判。

3. LNN 在系统中的核心作用

LNN 在 LnMem 里干 三件事，对应三个网络层级：

层级叫什么负责输入输出
1 phase2 backbone 把瞬时 AU 翻译成有时间记忆的 64 维状态 每帧 20 维 AU 8 类表情 state + 64 维 hidden state
2 intent_head 从隐状态判断你想表达什么 最近 10s 的 hidden state 窗口 三类意图概率（正/负/无）
3 τ-bias 个性化层 把"你这个人"编码到时间常数里 累积的反馈 每用户独立的 3KB τ 偏置向量

⚠️ 注意：v0.1 LNN 角色重定义（ADR-028）

LNN 不再是 "24h AU 序列预测器"（那个目标太大、太远），而是 "实时三分类意图估计 + 用户反馈闭环"。

原因：川哥真正想要的是 "前十几秒到几分钟的意图预判"，不是"明天你会不会笑"。
详见 docs/decisions/028-lnn-role-redefine-online-intent.md。

关键设计点

  • 不重启服务：训完新 ckpt 后 daemon 60s 内自动检测 symlink target 变化 → 调 inferencer._load_intent_head_ckpt() 1s 线性过渡 → 推理不中断
  • 主动学习不打扰：watcher v2 用 6 触发器优先级单选（不是 OR），只在 LNN 真不确定时问，弹窗写明白"为什么这次问你"
  • 反馈数据驱动训练：cursor-based 双门（自上次训练后增量 ≥10 + 距上次 ≥6h），防止反复训同一批

5. LNN 内部：LTC 微分方程是什么

传统 RNN 每步是离散的：h(t+1) = f(h(t), x(t))。
LNN（液态神经网络）的每个神经元是连续时间的常微分方程：

dh(t)/dt = -[1/τ(t,x,h)] · h(t) + f(t,x,h) · A

关键：时间常数 τ 不是常数，是 (t, x, h) 的函数——每个神经元都能动态决定"我对这个输入要慢慢消化还是快速反应"。

3 个非平凡设计

① τ 可学 + 用户 bias

τ = softplus(W·x + b_τ + bias_user)，其中 bias_user 是每个用户独立的小向量（几 KB）。

  • 川哥的 bias 让 τ 偏大 → LNN 对川哥的"皱眉"反应慢一点（因为他经常深思）
  • 另一个用户 bias 不同 → LNN 对皱眉立刻判断为"负面"

② dt-aware 时间步

训练时 daemon 30Hz，部署后 1.07Hz——LNN 把实际帧间隔传给 ODE solver，演化速度自适应不同帧率。传统 RNN 跨 fps 部署就废。

③ 在线漂移而不是 retrain

新反馈来了，不动 backbone，只更新 bias_user（3KB）。CPU 几毫秒搞定。
对比 LoRA 微调（几 MB + 几分钟）—— LNN τ-bias 漂移可以做真正的"用户级实时学习"。

6. 产生的价值：4 个无可替代

价值具体表现对比替代方案
① 超轻量个性化 每用户 3KB 的 τ-bias 就能编码"这个人" LoRA 几 MB / 全模型微调几 GB
② 真在线学习 反馈 → 30ms 内更新 bias，下次预测就变 RAG 检索靠"翻历史"不是真学到 / 传统模型需 retrain
③ 时间感知 同一模型支持 1Hz 或 30Hz，dt-aware ODE 自动适配 固定步长 RNN 跨 fps 必崩
④ 物理可解释 τ 大 = 慢神经元 / τ 小 = 快神经元，bias 漂移有物理意义 Transformer attention 权重难解释

💡 一个具体场景

川哥习惯思考时会皱眉 30 秒。

  • 传统系统：每次都问"你不开心吗？"骚扰
  • LnMem：3 天后川哥的 τ-bias 调高了 "皱眉→负面" 通路的时间常数，30 秒短皱眉不再触发误报；但持续 2 分钟皱眉 + 头部下垂 → 真触发关怀

🎯 关键判断（川哥钦定 P-1 LNN-FIRST 最高准则）

"凡涉及时间 / 演化 / 记忆 / 个性化，第一性原理必须是 LTC/CfC 微分方程。"

这是 LnMem 与所有同类系统的根本分界——"记忆是物理状态的连续演化"，不是"文本的离散存储"。

8. 与传统深度学习的差异（RNN / LSTM / Transformer）

对比维度 RNN / LSTM Transformer LNN（LTC/CfC）
时间建模 离散步长固定 位置编码近似 连续 ODE 自适应步长
时间常数 τ 无 / 隐含在参数 无 每神经元独立 + 可学 + 可个性化
跨 fps 部署 必须 retrain 需重新设位置编码 dt-aware 直接换 fps
个性化机制 fine-tune 全模型 LoRA（几 MB） τ-bias（3KB）
在线学习 难 —— catastrophic forgetting 难 —— 计算密集 τ-bias 漂移可控不爆
推理成本 O(T·H²) O(T²·D) O(T·H²) 但 H 很小
可解释性 低 低（attention 难读） 高 —— τ 直接对应"反应速度"
适合场景 序列分类 / 翻译 NLP / 大规模生成 实时多模态感知 + 个性化

📌 LNN 不是要取代 Transformer

Transformer 在大规模知识 + 文本生成上无可替代。LNN 的优势在持续实时感知 + 极轻量个性化 + 时间动力学这种 Transformer 不擅长的场景。

LnMem 实际上是组合架构：

  • LNN 做实时心脏（毫秒级感知 + 个性化）
  • LLM（Gemini / DeepSeek）做事件总结 / 自然语言交互（按需调用，不实时）
