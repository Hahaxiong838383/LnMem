## 0. M0 启动检查清单（v1.1 · 单人 + AI 协作模式）

> v1.1 路线 B（[`../docs/decisions/001-route-b-single-founder-ai-mode.md`](../docs/decisions/001-route-b-single-founder-ai-mode.md)）：单人启动，无团队招聘 / 算力采购环节。M0 第一周不进入"开发"，先做"破雷 + 基础设施"。

**P0（阻塞性，W1 内必做）**：

- [ ] **🔴 ncps τ 偏置 spike 三阶段**（[`../docs/memory-architecture.md`](../docs/memory-architecture.md) §7.5）：Day 1 能跑 / Day 2-3 训练稳定 / Day 4-5 5 主人区分度。**红 → 立即触发 D5 回退（FiLM > BitFit+LoRA(2) > 原 LoRA）**
- [ ] **种子用户**：10 名候选清单（不签约也行，**有名字**）
- [ ] **类型 3 数据**：W1 启动收集 + **占比监控仪表盘**（老板占比 > 50% 自动暂停贡献，转向其他来源或合成数据补足）
- [ ] **用户研究 + 假门测试 v0**：5-10 个深度访谈（合并执行）："你今天遇到的麻烦中 AI 帮不上忙的是哪些"+"陪你数年的 AI 这个概念你听懂了吗，你愿意付多少"。**v0 不看具体价格数字，看概念被听懂程度 + 否定信号 + 自发追问**
- [ ] **飞书周报 pipeline**：mycc 范畴内能力扩展，每周自动整理 git log + 评估指标 + 三色门槛触线告警

**P1（W1 末完成）**：

- [ ] **vibecoding SOP**：PR 三道门 + cc/codex 冲突诊断流程模板（基于 [`../CLAUDE.md`](../CLAUDE.md) §3 + §3.1）
- [ ] **ADR 起步**：[`../docs/decisions/`](../docs/decisions/) 目录 + 第 1 篇 ADR（路线 B 决策本身）
- [ ] **onboarding 手册骨架**：[`../docs/onboarding.md`](../docs/onboarding.md) 30 分钟新成员上手手册（M3 末扩团队前必须完整）
- [ ] **W1 末 retro**：cc + codex 联合复盘第一周

**P2（W2-W4）**：

- [ ] **`evals/` 模块**：中文 LongMemEval 风格 100 题 + 三色判定自动化 + W&B self-hosted 实时仪表盘
- [ ] **`synthetic_data_generator/`**：类型 1/2/3 三类 pipeline 跑通，1 万合成对话 + 50 虚拟主人 ×30 天
- [ ] **`universal_grammar_parser/`**：20 槽 schema_v1 草稿 + slot extractor v0
- [ ] **`graphiti_zh_adapter/`**：bi-temporal KG 中文适配 + GLiNER-multilingual entity 抽取
- [ ] **🆕 M0 末 working slice**（验收标准）：
  - 端到端最小场景：麦克风 → Fun-ASR → Parser 拆 P0+P1 槽位 → 写入 KG → 30 分钟后自然语言查询返回
  - P0 槽位填充正确率 100%（10 句样本）/ 召回率 100%（30 分钟窗口内逐句精确匹配）/ 端到端延迟 < 5s / 不要求 LNN 介入

**Why**：v1.1 把"团队/算力到位"从 W1 阻塞链拿掉，剩下的真正阻塞项是 ① ncps spike 破雷 ② 种子用户清单 ③ 类型 3 数据起步。

## 1. 月度里程碑（vibecoding 提速版）

每个月含三段：**核心交付 / 用户感知升级 / 三色检查项**。

### M0 · 基础设施 + 万能语法 v0

- **核心交付**：`synthetic_data_generator/`、`universal_grammar_parser/`、`graphiti_zh_adapter/`、20 槽 schema_v1 冻结
- **合成数据**：类型 1 / 类型 2 / 类型 3 三类 pipeline 跑通，M0 末产出 1 万条对话 + 50 虚拟主人 ×30 天 + 100h 真实交互
- **用户感知**：（内测）"我跟你说一句话，你能拆出主语谓语+复述"
- **三色检查项**：P0 召回 / Graphiti 中文闭环 / pipeline 跑通

### M1 · LNN Layer 1-2 雏形

- **核心交付**：`lnn_core/`（L1+L2 ncps 封装）、`slot_probe/`、L1+L2 端到端预训练完成
- **关键决策**：M1 末冻结万能语法 schema v1（v0.3 §12）
- **用户感知**：（内测）"你能感觉到我的情绪变化"+"上周三和谁吃饭"
- **三色检查项（M1 末第一次评估）**：见 §3 三色判定表

### M2 · 事件分割 + 状态摘要

- **核心交付**：`boundary_gate/`（v0 规则）、`event_tensor/`、`state_summary/`
- **假门测试启动**：v0.3 §9 风险——给种子用户看 demo 视频问"你愿意每月付多少钱"
- **用户感知**：（内测）"你知道我什么时候在干一件新事" + 完整对话流
- **三色检查项（M2 末第二次评估）**

### M3 · 个性化 v0 + 记忆界面 v0

- **核心交付**：`personalization/v0/`（**LNN 原生三件套：τ 偏置 + FiLM + 槽位偏好向量**，3KB/用户，CPU 推理）、`memory_ui/`（**读/删 v0** — 不可妥协 §10.1#6）、多设备同步基础
- **用户感知**：（内测）"提醒风格开始像我习惯的方式" + 用户首次能看到 AI 记了什么、并删除任意一条
- **三色检查项（M3 末第三次评估）**
- **关键校验**（[`../docs/memory-architecture.md`](../docs/memory-architecture.md) §7.5）：① τ 偏置容量曲线（1KB/4KB/16KB 行为区分度）② FiLM × LTC 联合训练稳定率 ③ system prompt 平均长度
- **学术埋点**：若 τ 容量曲线对数收敛（小预算大收益），M6 启动论文准备《Per-user τ-Bias for LTC Networks》

### M4 · 🎯 MVP α 上线

- **核心交付**：所有 M0-M3 模块通过 `agent_core/` 编排；居家场景 Web/App 上线
- **用户感知**：10 名种子用户开始日均使用
- **关键验证**：双门 + 四象限（[`../docs/product-definition.md`](../docs/product-definition.md) §13.1）
  - 用户行为门：6/10 第 2 周仍主动使用 / 周交互 ≥5 次 / 2 周无 >3 崩溃
  - 能力门：记忆问答正确率 ≥ 60% / P0 召回 ≥ 90%
- **老板独立计数**："第 0 号用户"平行体验，不入主验证样本

### M5 · CLS 雏形 + 记忆编辑界面

- **核心交付**：`cls_consolidation/`、`memory_ui/` 编辑功能 + 「记忆账本」v0、KG 治理分层启动
- **用户感知**：「今日小结」首次出现 + 用户能修正 AI 的错误理解

### M6 · 车载试点

- **核心交付**：`automotive_adapter/`、`lfm2_offline/`、Jetson Orin + USB 投屏
- **用户感知**：3 名车主通勤连续 1 周

### M7-M8 · 🎯 MVP β 上线

- **核心交付**：`personalization/v1/`（**v0.3.x 三件套全量**：τ 偏置生产化 + FiLM 调制稳定性优化 + 偏好向量在线学习）、`active_inference/v0/`、**LLM 语言风格路径决策点**（评估 system prompt token 成本 vs LoRA rank=2，按盈亏点切换）
- **用户感知**：扩到 25–50 用户，付费/邀请制；长期习惯被稳定继承

### M9 · 主动建议接受

- **核心交付**：`proactive_advisor/` + Active Inference + 记忆驱动建议
- **用户感知**：主动建议接受率 ≥ 30%（疲惫时建议休息等）

### M10 · 跨设备同步

- **核心交付**：`multi_device_sync/`、个性化 v1 全量
- **用户感知**：跨设备无缝（家里/车里/手机同一个它）

### M11 · 长期 KG 治理全量生效

- **核心交付**：`kg_governance/`（热/温/冷分层 + 自动归档全量生效）
- **用户感知**：单用户连续 30 天无重大记忆丢失，可发 alpha demo

### M12 · 18 月架构提前成型

- **核心交付**：L6（元认知）+ L7（共生协议）真实实现起步
- **用户感知**：元认知开始辅助决策

## 2. M2-M5 惊喜时刻清单（必须刻意埋点）

| 时刻 | 触发月 | 设计要点 |
|------|-------|---------|
| AI 第一次主动提到上周的事 | M2 | 用户从未提过的话题，AI 主动联系到一周前的对话 |
| AI 第一次根据习惯调整建议方式 | M3 | 同一个建议，对不同用户用不同语气 |
| AI 第一次准确识别情绪并恰当回应 | M4 | 不只是识别，而是用合适的方式回应——有时是沉默 |
| AI 第一次拒绝某件不合适的事 | M5 | "你说想跟他聊聊，但你上次提到他时心率明显升高——要不要先想想再说？" |
| AI 第一次主动提出"我可能误解了你" | M5 | 不等用户纠正，自己监测到推断置信度低时主动澄清 |

详见独立文档《惊喜时刻设计手册》（v0.4 启动）。

## 3. 三色判定（v0.3 §7.3）

每月末执行，**红区强制停下问老板，黄区加强观察不回退，绿区按计划推进**。

| 评估时点 | 检查项 | 红区（立即回退） | 黄区（加强不回退） | 绿区（按计划） |
|---------|-------|----------------|-----------------|--------------|
| **M1 末** | P0 召回 / Graphiti 中文闭环 / 合成数据 pipeline | P0 < 60% 或 Graphiti 完全不可用 或 pipeline 没跑通 | P0 60-80% / Graphiti F1 < 0.5 / pipeline 跑通但质量不稳 | 全部达标 |
| **M2 末** | LNN Layer 1-2 状态有效性 / 事件分割 v0 可用性 | LNN 训练完全发散 或 事件分割 F1 < 0.3 | LNN 状态弱可用 / 事件分割 F1 0.3-0.5 | 全部达标 |
| **M3 末** | 整体进度 vs vibecoding 预期 | 滞后 > 50% | 滞后 30-50% | 滞后 < 30% |

**红区行动**：M4 改为"内测 demo（仅团队内部）"，外部种子用户推到 M5 / 进一步推到 M6 / 回退到 M5 上 MVP α
**黄区行动**：保持 M4 节奏 + 该项目加配资源 + 下次评估前必须爬出黄区
**绿区行动**：按计划推进

**Why（红黄绿）**：刚性"任一项不达标"在新工程 M1 末几乎必然触发，摧毁团队心理动量本身就是激进时间线的失败模式。

## 3.1 节奏弹性规则（v1.1 新增）

> **激进时间线 ≠ 每个里程碑按时**，是每个交付物被认真对待。允许弹性，但弹性边界必须明示。

| 阶段 | 默认 | 允许弹性 | 弹性触发条件（必须明示） | 不可妥协边界 |
|------|------|---------|------------------------|------------|
| M0 | 4 周 | +2 周 | spike 失败需 Plan B / 工程量超预期 / 关键依赖（API/库版本）卡顿 | 不超过 6 周 |
| M1-M3 | 各 1 月 | +1 周/段 | 三色黄区且需重训 | 累计不超过 +3 周 |
| M4 MVP α | 5 月末 | +0.5 月 | 用户行为门未过需小延 | **5.5 月封顶** — 超过停下来全盘重评 |

**每周 retro 检查弹性消耗速度**：W1 末已用掉 3 周招募/破雷窗口的话，W2 末必须做"加速 / 接受延期"决策，不许默默拖延。

## 3.2 风险登记册（v1.1）

> 工程视角的风险优先级，比 [`../docs/product-definition.md`](../docs/product-definition.md) §9 更具体。

| 风险 | 何时知道 | 后果 | 处置 |
|------|---------|------|------|
| **🔴 ncps τ 偏置三阶段任一红** | M0 W1 spike | M3 个性化路径要重做 | 立即触发 D5 回退（FiLM > BitFit+LoRA(2) > 原 LoRA），ADR 记录 |
| **🔴 类型 3 数据老板占比失控** | M0 W2 起每日监控 | 模型在老板个人风格上过拟合 | 占比触线（>50%）自动暂停老板贡献，转向其他来源或合成数据补足 |
| **🔴 Graphiti 中文 entity F1 < 0.5** | M0 末 | L2 召回质量低 | 老板亲标 100 条对照集 / 切换 GLiNER-Chinese / 降级为 BM25+向量 |
| **🔴 合成数据污染 LNN 训练** | M2 末 | LNN 学到合成偏好不是真实偏好 | 立即停合成训练，全量回退真实数据 + 多模态大模型直出 |
| **🟡 LLM API 五家轮换限流** | M0 W2 起 | pipeline 卡顿 | 多家并行 + 本地 vLLM 兜底 |
| **🟡 单人精力不够扛 M3 多模态训练** | M3 末 | 进度大幅滞后 | M3 末决策点：扩 1-2 人专攻 ML，或缩范围到单模态 MVP α |
| **🟡 老板"第 0 号用户"偏差** | M3 末 | 主样本被污染 | 见 [`../docs/product-definition.md`](../docs/product-definition.md) §13.3 四条缓解 |

## 5. 不可妥协的 6 项（v0.3 §10.1）

任何里程碑不允许妥协这 6 项：

1. 万能语法 20 槽作为全系统共享 schema
2. 多时间尺度 LNN 心智核心（哪怕只有两层）
3. CLS 双系统离线 consolidation 流程
4. per-user 个性化栈（**v0.3.x 更新**：LNN 原生三件套 = τ 偏置 + FiLM + 槽位偏好向量，3KB/用户）
5. 居家+车载双场景统一架构
6. 用户可见、可编辑、可治理的记忆界面

**任何对这 6 项的妥协建议必须先停下问老板**（[`../CLAUDE.md`](../CLAUDE.md) §5）。
